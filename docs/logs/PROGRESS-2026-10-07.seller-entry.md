# Progress — 7 October 2026 — Seller complaints, category requests, shipments

Frontend only, by owner instruction. No backend file, route, migration or test was changed or run. Not built or browser-tested (no PHP/Node in the working environment).

- **Complaints (new):** `seller/complaints/index.blade.php`, `complaints.css`; sidebar link in `components/seller/layout.blade.php`, shown only when `seller.complaints.index` exists.

Header with Live pill, five stat cards using `total-shipments-icon.svg`, `to-ship-icon.svg`, `in-transit-icon.svg`, `delivered-icon.svg`, `cancelled-icon.svg` (in `public/assets/icons/seller/`), status tabs with counts, search, courier and date dropdowns (presets and custom range), Orders-style table with avatar, five-stage progress, ETA, copy tracking number, status pill, View and Print label, clickable rows, numbered footer pager, phone card layout. Files: `shipments/index.blade.php`, `shipments/detail.blade.php`, `shipments/partials/progress.blade.php`, `shipments.css`, `shipments.js`.
