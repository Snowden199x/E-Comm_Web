# Progress - 16 November 2026

## Philippines Logistics demo network and manager accounts

- Added `PhilippinesLogisticsCompanySeeder`, an opt-in idempotent seeder that creates one approved Company-level Logistics account for each entry in the bundled PSGC province/area catalog. The seeder also creates one Province Hub and a Station Hub for every municipality/city in that province; no fictitious Sub Station level is seeded. Province Hub and Station Hub manager accounts are linked through `facility_staff`.
- Demo logins use `logistics.<province-slug>@vendo.com` and shared password `password123`. The seeder can be run explicitly in the presentation environment and is not registered in the default seeder.
- Added `logistics:demo-accounts-pdf [path]`; generated the credential PDF in Downloads, covering all 1,796 Company and facility-manager accounts with restrictive file permissions. The PDF was rendered and visually checked.
- Seeded the local `vendo` database: 82 Logistics Companies, 82 Province Hub managers, and 1,632 Station Hub managers (1,796 accounts), with 1,714 Province/Station Hub facilities. No migration was needed; one pickup-photo migration remains pending and is unrelated.
- The seeder hashes the shared password once per run to keep repeat seeding practical. It remains opt-in and is not registered in the default seeder.

## Admin User Management Logistics filter

- Updated the Logistics stat card and server-side filter to show main Logistics Company accounts (`logistics_center` and legacy `logistics`) only. The aggregate count and total-user count use that same role set; Province Hub and Station Hub managers are excluded.
- Seller and Buyer query branches and UI behavior were left unchanged. No migration was added. Owner browser verification is pending.
