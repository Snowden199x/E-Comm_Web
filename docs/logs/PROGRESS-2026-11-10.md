## Rider app download on the Logistics landing page

The landing page already had the "Looking to ride, not run a business?" callout, a "Get the Vendo Rider App" button and a QR image, but both pointed at `/logistics/get-the-app`, which rendered the `coming-soon` page — the Rider app did not exist publicly yet.

- **Route.** `logistics.rider-app` now redirects (302, `redirect()->away`) to `config('services.vendo.rider_app_url')` instead of rendering the placeholder. The landing markup and the printed QR are unchanged; the QR decodes to `https://vendo-ph.app/logistics/get-the-app`, so it keeps working.
- **Config.** `config/services.php` gained `vendo.rider_app_url`, defaulting to `https://github.com/Snowden199x/E-Comm_Mobile/releases/latest/download/vendo-rider.apk` and overridable with `RIDER_APP_DOWNLOAD_URL`. Because the URL uses GitHub's `releases/latest/download/<asset>` form, publishing a new release updates the download without touching the site; moving to Google Play later is an env change only.
- **Why GitHub.** Hobby Vercel is non-commercial-only and caps static uploads at 100 MB, Render's free plan includes ~5 GB of outbound bandwidth a month, and Cloudflare Pages caps a file at 25 MiB — none fit a 38–107 MB APK. GitHub Releases allows 2 GiB per asset with no bandwidth limit, and the mobile repository is public.
- **Spec.** [Rider app download](../features/logistics/rider-app-download/spec.md). The Android build, signing key and APK sizes are documented in the mobile repository: `E-Comm_Mobile/docs/features/rider-app-release.md`.

**Verified:** `php -l` on `config/services.php` and `routes/web.php`; `php artisan route:list --name=rider-app` finds one route; a local `php artisan serve` request to `/logistics/get-the-app` returns `302` with the GitHub URL from config. **Not verified:** the redirect was not followed against a published release, because the APK asset has not been uploaded to GitHub yet, and the QR was not rescanned on a phone.

**Known gaps:** the asset must be named `vendo-rider.apk` in a published (not draft/pre-release) GitHub release, otherwise the link 404s. Direct APKs do not auto-update. No Play Store listing yet.
